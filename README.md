# Evaluation Lab

A short browser game about evaluating a policy: one child benefit, four comparisons, one question. Did it work, and how would we know?

Play: https://rszarf-1.github.io/evaluation-lab/

About 20 minutes, 12 questions. At the end the game shows a result code to send to the teacher. It runs in the browser and stores nothing on a server.

Course: Redistribution Policy and Politics, Session 7.
